# CampusConnect Design System

## 1. Design Overview

CampusConnect uses a clean, modern and student-friendly interface. The design focuses on simplicity, accessibility and easy navigation.

## 2. Color Palette

| Purpose | Color | Hex Code |
|---|---|---|
| Primary | Blue | #2563EB |
| Secondary | Light Blue | #DBEAFE |
| Background | Light Gray | #F8FAFC |
| Cards | White | #FFFFFF |
| Main Text | Dark Gray | #1F2937 |
| Success | Green | #16A34A |
| Warning | Orange | #F97316 |

## 3. Typography

- Font family: Arial / Sans-serif
- Page headings: Bold
- Section headings: Semibold
- Body text: Regular
- Buttons: Semibold

## 4. Components

### Navbar
Displays the CampusConnect title and student navigation options.

### Sidebar
Provides links to Dashboard, Profile, Announcements, Events and Assignments.

### Dashboard Cards
Display important student information and activity counts.

### Announcement Cards
Display college notices with title, date and description.

### Event Cards
Display event details and registration options.

### Assignment Tracker
Allows students to mark assignments as completed.

## 5. Layout

- Responsive grid layout
- Rounded cards and buttons
- Consistent spacing
- Clear section headings
- Mobile-friendly navigation

## 6. Interaction

- Hover effects on navigation links
- Event registration button
- Assignment completion button
- React Context API for shared application state
- Local Storage for saving selected student activities

## 7. Technology

- Next.js
- React.js
- JavaScript
- Tailwind CSS
